QUICK START
================================================================================

Step 1: Install Dependencies
  $ pip install -r py_files/requirements.txt

Step 2: Set Up Environment
  Create file: .env
  Add: GROQ_API_KEY=your_key_here

Step 3: Run a Chain
  $ cd py_files
  $ python traditional.py

Step 4: View Results
  $ cd ../results
  $ cat traditional_result.txt

TROUBLESHOOTING QUICK REFERENCE
================================================================================

Issue: Module not found
→ Solution: pip install -r py_files/requirements.txt

Issue: API key not found
→ Solution: Create .env file with GROQ_API_KEY

Issue: Chain times out
→ Solution: Use parallel chains or simpler prompts

Issue: Rate limit exceeded
→ Solution: Add time.sleep(2) between requests

Issue: Memory issues with large conversations
→ Solution: Trim history to keep only last 10-20 messages
